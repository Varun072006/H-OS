# Frontend

Web-based user interfaces for HumanOS.

## Modules

### `dashboard/`
Real-time monitoring dashboard for observing human state, risk indicators, and system health across one or more camera feeds. Built with React and TypeScript.

### `visualizer/`
Interactive 3D skeleton and motion graph visualizer for debugging, demonstration, and analysis. Renders joint trajectories, motion embeddings, and prediction overlays.

## Technology

- **Framework**: React 18+ with TypeScript
- **Styling**: CSS Modules or Styled Components
- **State Management**: Zustand or Redux Toolkit
- **3D Rendering**: Three.js / React Three Fiber (for skeleton visualization)
- **Charts**: Recharts or D3.js (for time-series metrics)

## Development

```bash
cd frontend
npm install
npm run dev
```
