# Dataset Datasheet: [Dataset Name]

> Template based on [Datasheets for Datasets (Gebru et al., 2021)](https://arxiv.org/abs/1803.09010)

## Motivation

- **Purpose**: Why was this dataset created?
- **Creators**: Who created the dataset and on behalf of which entity?
- **Funding**: Who funded the creation of the dataset?

## Composition

- **Instances**: What do the instances represent? (e.g., skeleton sequences of human activities)
- **Count**: How many instances are in the dataset?
- **Sampling**: Is there a sampling strategy?
- **Missing Data**: Is any information missing from individual instances?
- **Confidentiality**: Does the dataset contain data that might be considered confidential?

## Collection Process

- **Mechanism**: How was the data collected? (e.g., Kinect sensor, RGB camera + pose estimation)
- **Collectors**: Who was involved in the data collection process?
- **Timeframe**: Over what timeframe was the data collected?
- **Consent**: Were individuals informed about the data collection? Did they consent?

## Preprocessing

- **Steps**: What preprocessing/cleaning was done?
- **Raw Data**: Is the raw data saved in addition to the preprocessed data?

## Uses

- **Prior Uses**: Has the dataset been used for any tasks already?
- **Potential Uses**: What other tasks could the dataset be used for?
- **Inappropriate Uses**: Are there tasks for which the dataset should not be used?

## Distribution

- **License**: Under what license is the dataset distributed?
- **Access**: How can the dataset be accessed?
- **Third-Party Restrictions**: Are there any restrictions on third-party use?

## Maintenance

- **Maintainer**: Who maintains the dataset?
- **Updates**: Will the dataset be updated? How often?
- **Contact**: How can the maintainer be contacted?
